# Invitación Romero Torres

Invitación digital responsive para celulares.

## Archivos

- `index.html` — estructura y contenido.
- `style.css` — diseño responsive y animaciones.
- `script.js` — apertura, cuenta regresiva y botón volver arriba.
- `portada.png` — portada de Canva.
- `invitacion.png` — diseño principal de Canva.

## Importante

En `index.html`, reemplaza `57XXXXXXXXXX` por el número real de WhatsApp para confirmaciones, usando código de país y sin espacios.

Ejemplo:

`573001234567`

## Publicar con GitHub Pages

Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
